# चक्रव्यूह · Chakravyuh War-Table

A 2 min 10 s cinematic explainer of the **Chakravyuh**, the spiral battle formation from Day 13 of the Mahabharata war, told as a tactical war-room briefing.

Everything is one self-contained `index.html`: Canvas 2D, inline CSS/JS, no frameworks, no CDNs, no image assets. The warrior portraits are drawn in code.

## Scenes
0. Cold open · चक्रव्यूह
1. द्रोण की रचना — Drona's Design
2. गर्भ में ज्ञान — Knowledge in the Womb
3. द्वार पर जयद्रथ — The Gatekeeper
4. प्रवेश — The Entry
5. सात महारथी — Seven Against One
6. रथ का पहिया — The Chariot Wheel
7. वीरगति — The Fall
8. अर्जुन की प्रतिज्ञा — Arjuna's Vow
9. End card · फिर से

## Controls
| Key | Action |
|---|---|
| Space | Play / pause |
| R | Replay from the start |
| M | Sound on/off (synthesized nagara drum + conch, muted by default) |
| L | Loop on/off |
| ← / → | Skip 5 s (Shift = one frame) |

Click the timeline at the bottom to seek. Add `#t=78.8` to the URL to open paused on a given moment.

## Run locally
Open `index.html` in any modern browser.
